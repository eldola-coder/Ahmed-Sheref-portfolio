# Ahmed Sheref Portfolio — 2026

Recruiter-focused personal portfolio for Ahmed Sheref.

## Highlights
- Responsive charcoal and mint design, readable typography, and consistent spacing
- CV-aligned projects, skills, experience, education, languages, and credentials
- Featured TickTick case study with CV-recorded installs and rating, AI integrations, Telegram workflows, Azure VM, and GitHub Actions
- Four project case studies using native dialogs with keyboard focus management
- Mobile navigation, skip link, visible keyboard focus, and reduced-motion support
- Direct email, LinkedIn, repository, demo, and updated local CV links
- SEO, Open Graph, Twitter Card, JSON-LD, canonical URL, and SVG favicon

## Content maintenance
- `index.html`: page content, project summaries, credentials, and contact details
- `projects.js`: detailed project descriptions, technologies, and external links
- `style.css`: responsive layout and design tokens
- `script.js`: navigation and accessible project dialogs
- `assets/Ahmed_Sh_Sheref_CV.pdf`: downloadable CV

TickTick figures are attributed to the supplied CV, rather than presented as a live counter. Certificate dates follow that CV; supplementary certificate images remain in `assets/`.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Deploy
The project is static and can be deployed to Vercel, Netlify, GitHub Pages, or any static host.
